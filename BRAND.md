# Centre Smoke Vape Shop brand system

The visual system is derived from the owner-supplied storefront artwork.

- Primary green: `#09620F` — buttons, links, active marks and the logo.
- Bright accent: `#A8DB17` — decorative highlights only; never small body text on white.
- Ink: `#090B0A` — headings and primary text.
- Soft green: `#EEF6EB` — section backgrounds and quiet surfaces.
- White: `#FFFFFF` — main canvas and high-contrast text on the primary green.

The typography is a bold, condensed-feeling system stack for display headings with a clean sans-serif body. The layout uses rounded white panels, black rules and curved green bands that echo the supplied window and door art. Focus rings use bright green against a black outline. All text/background pairs meet normal-text contrast; the bright accent is decorative.

The storefront image is a design reference, not published as documentary photography. The site hero is explicitly described as a brand illustration.
