# Centre Smoke Vape Shop

Official storefront source for `centresmokeshop.com`.

The site uses the owner-supplied black, white and green storefront identity. Business facts that have not yet been approved—hours, full postal address, inventory source, StoreCode, delivery configuration and provider routing—fail closed and are not guessed.

## Local checks

Use Node.js 22 or newer.

```powershell
npm install
npm run verify
npm run dev
```

The public preview remains `noindex` until the complete NAP, operating data and launch checklist are approved and live-verified.
